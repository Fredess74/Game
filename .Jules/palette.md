## 2025-06-11 - Dynamic Play/Pause and Keyframe Button Accessibility
**Learning:** When adding focus states (`focus-visible:ring-2`) and keyboard navigation support to a dynamic toggle button (like Play/Pause), it is essential to ensure that not only the icon updates, but also the `aria-label` and `title` attributes update dynamically. Additionally, for disabled icon buttons (like a disabled Keyframe button), providing a dynamic `title` attribute explaining *why* it's disabled (e.g., "Select an actor to add a keyframe") and adding a `disabled:cursor-not-allowed` class drastically improves context for both screen reader users and sighted users hovering over the button.
**Action:** Always map the state driving the icon (e.g., `isPlaying`) to `aria-label` and `title` on toggle buttons. For disabled actions, provide contextual `title` text and the `cursor-not-allowed` class to clarify the disabled state.
