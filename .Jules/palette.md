## 2024-03-11 - Timeline Controls Accessibility
**Learning:** Icon-only playback controls and conditionally disabled action buttons in the Timeline component lack context for assistive technology users and sighted users trying to understand why a button is disabled. The lack of standard focus indicators also degrades keyboard navigation.
**Action:** Consistently apply `aria-label` and `title` to icon-only buttons. Use dynamic `title` attributes (e.g., "Select an actor to add a keyframe" instead of just "Add keyframe" when disabled) and the `disabled:cursor-not-allowed` class on conditionally disabled controls to explain state constraints. Ensure all interactive elements include explicit focus states (`focus-visible:ring-2`, `focus-visible:outline-none`, and `rounded` for clean rings).
