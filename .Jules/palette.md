## 2024-05-18 - Improve Timeline Toolbar UX
**Learning:** Icon-only buttons require explicit `aria-label` attributes for accessibility and `title` attributes for visual tooltips, especially when state is dynamic (e.g., Play vs. Pause). Furthermore, disabled action buttons should explain *why* they are disabled using a dynamic `title`, and should use the `disabled:cursor-not-allowed` utility to provide clear visual feedback. Keyboard navigation relies heavily on clear focus indicators which can be achieved robustly with `focus-visible` utility classes.
**Action:** Always add `aria-label` and `title` to icon-only buttons. Ensure dynamic action buttons provide contextual disabled explanations. Apply consistent `focus-visible` styles to all interactive elements to support keyboard users without cluttering mouse interaction.
