## 2024-04-24 - Playwright Verification for Dynamic Button State Locators
**Learning:** When using Playwright to verify dynamic button states (e.g., when the `disabled` or `aria-busy` state of a button changes and its inner text icon simultaneously changes, as with the "Export Video" button), using text-based locators like `has_text="..."` can be extremely brittle. The exact text node inside the React component might quickly change or not perfectly match the query if icons are inline.
**Action:** Always prefer robust attribute-based locators like `get_by_title()`, `get_by_role()`, or `locator("button[aria-busy='true']")` after an interaction when verifying state changes. Specifically, wait for the state attribute itself to appear, rather than depending on the interim text.
