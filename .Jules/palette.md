## 2026-06-07 - Native tooltips vs visual verification\n **Learning:** Native browser tooltips (via the `title` attribute) and cursor states are difficult to capture reliably using visual Playwright screenshots. \n **Action:** When verifying UI attributes like tooltips in Playwright, explicitly assert the attribute values via DOM queries (`page.locator().get_attribute('title')`) and log them instead of relying solely on visual inspection of the screenshot.
