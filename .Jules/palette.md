## 2024-04-09 - Accessible File Uploads
**Learning:** Wrapping an `<input type="file" className="hidden">` in a `<label>` is a common pattern for styling upload buttons, but it makes the element entirely inaccessible to keyboard navigation because hidden inputs cannot receive focus, and labels don't receive focus natively. Additionally, in React, file inputs will silently fail to trigger `onChange` if the user tries to upload the same file twice in a row because the DOM element's `value` hasn't changed.
**Action:** Use a visible, focusable `<button>` element with an `onClick` handler that calls `.click()` on the hidden file input via a `useRef`. Always reset the hidden input's value (`ref.current.value = ''`) inside the `onChange` handler before processing the file so the user can re-upload the same file if needed.
