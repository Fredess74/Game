## 2025-05-20 - [Timeline Toolbar Accessibility]
**Learning:** Icon-only buttons in dense toolbars like timelines require both `aria-label` (for screen readers) and `title` (for mouse user tooltips) to be discoverable. The "disabled" state in modern web apps needs to explicitly explain *why* an action is unavailable, turning a frustrating "grayed out" button into a helpful instruction (e.g., "Select an actor to add a keyframe"). Focus states (`focus-visible`) are critical here since editors are often keyboard-driven.
**Action:** When adding or modifying icon toolbars (like Timeline, Properties, or Asset Library panels), standard practice should be: `aria-label` + `title` + `focus-visible:ring-2 focus-visible:ring-editor-accent`. Disabled states must include a dynamic `title` explaining the requirement and `disabled:cursor-not-allowed`.
